# Project Lab · 관심 지도 V2.1 외부 검토본

중·고등학생 대상 15개 활동 선택형 전공 탐색 체험입니다.

## 실행 및 배포

GitHub Pages에서 main 브랜치의 /(root)를 게시합니다. 사이트 첫 주소 index.html에서 바로 실행됩니다. 별도 설치나 빌드는 필요하지 않습니다.

## 검토 범위

- 휴대폰 세로 화면의 가독성과 버튼 조작
- 15문항 이해도 및 활동 선택의 쉬움
- 결과 설명, 전공 상세, 링크 공유, 이미지 저장

## 데이터와 한계

이 버전에는 참가자 응답이나 의견을 수집하는 서버·분석 도구가 없습니다. 결과 링크의 #map 부분에는 15개 선택이 포함되어, 링크를 받은 사람이 해당 응답과 결과를 볼 수 있습니다. 호스팅 제공자는 웹 요청에 대한 기본 로그를 처리할 수 있습니다.

관심과 전공 연결은 탐색을 위한 초안이며, 적성이나 능력을 측정하는 검사가 아닙니다. 최대 동시 접속 인원은 공개 배포 환경에서 측정하지 않았습니다.

## 버전 보존

V2.1 실행 파일과 사용 중인 로고 2개를 원본을 복사했으며, 웹 업로드를 위해 로고 2개의 상대경로에서 assets/ 접두어만 제거했습니다. 기존 V1/V2 및 원본 AI 로고, 분석 문서, 캡처용 코드는 이 저장소에 포함하지 않습니다. 문항 의미나 계산 규칙을 바꿀 때는 새 저장소 또는 새 버전 경로로 추가하고 이 V2.1 주소를 보존합니다.
